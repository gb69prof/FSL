# Leopardi – Percorso fisico (Collina dell’Infinito 360°)

Questa è una mini web-app **statica** pensata per GitHub Pages: simula un “ambiente fisico” a 360° (panorama equirettangolare) che puoi esplorare trascinando a sinistra/destra.

## Come usarla su GitHub Pages
1. Crea un repo (es. `leopardi-360`)
2. Carica tutto il contenuto di questa cartella (mantieni la struttura)
3. In **Settings → Pages** abilita Pages su branch `main` (root)
4. Apri l’URL di Pages.

## Controlli
- Trascina (mouse) o un dito (touch) per guardare
- Trackpad/rotellina o pinch per lo zoom
- Frecce / WASD per muoverti
- Pulsante **Reset** per centrare
- Pulsante **Cammina** per scorrere lentamente

## File
- `index.html` – la web app (tutto in un file, senza librerie esterne)
- `assets/collina_infinito_360.jpg` – panorama 360° (seamless orizzontale)

## Nota didattica
Il panorama è una ricostruzione **artistica** ispirata alla Collina dell’Infinito: se vuoi, posso sostituirla con una foto reale (ma serve una foto equirettangolare 360° o un set da convertire).
