# Foggia – SCOPRI (demo)
Questa è una demo pronta per GitHub Pages.

## Pagine
- `index.html` (home minimale)
- `scopri.html` (pagina SCOPRI)

## Funzioni
- Home (icona 🏠) torna a `index.html`
- Video: apre YouTube. A fine video torna automaticamente all'immagine (senza autoplay)
- Galleria: apre embed Sketchfab + strip immagini scorrevoli
- 3D: apre solo embed Sketchfab
- Guida AI: apre il link in una nuova scheda

## Note
- Per aggiungere contenuti alle altre tappe: modifica `assets/js/app.js` nella struttura `SECTIONS`.
